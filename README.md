## 🚀 How to Run the Code

### Prerequisites
Make sure you have Python installed on your system. You can check by running:
```bash
python --version
```

### Running a Lesson
To run any of the lessons, navigate to the `code` folder and execute the script using the Python interpreter.

**Example: Running Lesson 08 (Mini-Chatbot)**
1. Open your terminal or command prompt.
2. Navigate to the project directory:
   ```bash
   cd python-ai/code
   ```
3. Run the specific file:
   ```bash
   python lesson_08_mini_chatbot.py
   ```
